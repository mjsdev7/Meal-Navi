# Meal Navi

**Plan smarter. Shop easier.**

Meal Navi is a full-stack meal planning application that helps users discover recipes, organise weekly meal plans, and automatically generate shopping lists.

This project is being developed to simplify meal planning while demonstrating modern full-stack web development techniques.

---

## Features

### Current
- User authentication (Register, Login, Logout)
- User profiles
- Recipe search
- Save favourite recipes
- Weekly meal planner
- Automatic shopping list generation
- Responsive design

### Planned
- Nutrition information
- High-protein recipe recommendations
- Pantry tracker
- Leftover meal suggestions
- Dark mode
